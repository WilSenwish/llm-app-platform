# src/ 目录说明

本仓库采用 **Maven 多模块** 布局，各模块的源码分别位于根目录下的独立模块目录中：

| 模块目录 | 说明 |
| --- | --- |
| `platform-core/` | 平台内核（SPI 规范、插件注册中心、前置编排与执行器） |
| `plugin-rag/` | RAG 问答插件（可插拔） |
| `gateway-service/`（week2 规划） | 独立 AI 模型网关微服务 |

`src/` 为规划文档中预留的“主项目源码”根目录。在当前多模块结构下，模块源码即由其各自目录承载，
`src/` 仅作占位与说明，不放置实际代码（避免与 Maven 模块目录重复）。
后续若有聚合层 / 共享代码，可在此目录新增对应模块。
